# i2 DECK - GRADE: DaVinci Resolve colour page, with the WHEELS page.
# This file goes on the Tracker's SD card as i2/Deck/grade.txt (replace the
# one there). REV 10 keeps the firmware from swapping it for its own.
#
# Page 1 COLOR: Resolve's keyboard shortcuts, as before. Printer lights: press
#   Printer Lights first (Color > Printer Light Hotkeys).
# Page 2 WHEELS (screen button 7 turns the page): Lift / Gamma / Gain /
#   Offset, Contrast and Sat. These pads and dials send MIDI on channel 2,
#   and the i2 GRADE WHEELS helper on the computer turns that into mouse
#   drags on Resolve's controls. Run the helper and learn the positions once
#   (see its README).
# LINK MIDI: pads and dials with a shortcut still send keys; the ones without
#   send MIDI. The Play / arrow / Copy / Insert buttons don't send keys in a
#   MIDI deck.
# Screen button 6 switches GRADE to Premiere (that side is gradepr.txt).
DECK GRADE
REV 10
APP DaVinci Resolve
LINK MIDI
COLOR FFB454

PAGE COLOR
BLOCK 1 NODES
K SER  Serial Node          | OPT+S
K PAR  Parallel Node        | OPT+P
K LAYR Layer Node           | OPT+L
K OUTS Outside Node         | OPT+O
K CIRC Circle Window        | OPT+C
K LIN  Linear Window        | OPT+Q
K POLY Polygon Window       | OPT+G
K CURV Curve Window         | OPT+B
K ND-  Previous Node        | SHIFT+OPT+;
K ND+  Next Node            | SHIFT+OPT+'
K NODE Node On / Off        | CMD+D
K BYP  Bypass Grades        | SHIFT+D
K RST  Reset Node           | SHIFT+HOME
K RSTG Reset Grade          | CMD+SHIFT+HOME
K RALL Reset Grades + Nodes | CMD+HOME
K AUTO Auto Color           | OPT+SHIFT+C
BLOCK 2 COMPARE
K GRAB Grab Still           | CMD+OPT+G
K WIPE Wipe On / Off        | CMD+W
K SPLT Split Screen         | CMD+OPT+W
K HILT Highlight            | SHIFT+H

K VPRV Previous Version     | CMD+B
K VDEF Default Version      | CMD+U

K PSTE Paste Grade          | CMD+V
K LDA  Load Memory A        | CMD+1
K LDB  Load Memory B        | CMD+2
K SVA  Save Memory A        | OPT+1
K SVB  Save Memory B        | OPT+2
BLOCK 3 LIGHTS + PLAY
K R+   Red +                | KP7
K G+   Green +              | KP8

K LITE Printer Lights       | CMD+OPT+`
K FULL Cinema Viewer        | P

K CLP- Previous Clip        | UP
K CLP+ Next Clip            | DOWN
K REV  Reverse              | J
K FWD  Forward              | L
DIAL 1 CLIPS   | DOWN | UP
DIAL 2 NODES   | SHIFT+OPT+' | SHIFT+OPT+;
DIAL 3 OFS RED | KP7 | KP4
DIAL 4 OFS GRN | KP8 | KP5
DIAL 5 OFS BLU | KP9 | KP6
